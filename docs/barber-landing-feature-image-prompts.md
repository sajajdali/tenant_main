# پرامپت عکس صفحات امکانات لندینگ آرایشگاه

این فایل برای ساخت تصاویر اختصاصی هر صفحه امکان در لندینگ آرایشگاه است. همه تصاویر باید یک خانواده بصری واحد داشته باشند تا وقتی کاربر بین صفحات امکانات جابه‌جا می‌شود، حس یک برند منسجم بگیرد.

    ## مشخصات ثابت همه تصاویر

    - اندازه اصلی: `1600x1000px`
    - نسبت تصویر: `16:10`
    - خروجی پیشنهادی: `webp` یا `png`
    - سبک: تصویر واقع‌گرایانه/سه‌بعدی نرم با UI mockup مدرن، مناسب SaaS آرایشگاهی
    - رنگ زمینه: مشکی گرم و لوکس `#0e0d0b`
    - رنگ کارت‌ها: زغالی گرم `#171512`
    - رنگ طلایی اصلی: `#c9a24a`
    - طلایی روشن برای هایلایت: `#e0c06e`
    - متن سفید گرم: `#f4f2ee`
    - متن فرعی: `#9c988d`
    - رنگ موفقیت: سبز ملایم `#34d399`
    - رنگ هشدار خیلی محدود: قرمز ملایم `#f87171`
    - فونت فارسی پیشنهادی برای متن داخل عکس: Vazirmatn یا یک فونت فارسی مدرن و خوانا
    - جهت متن‌ها: راست‌به‌چپ
    - فضای امن متن: حداقل ۹۰px از لبه‌ها
    - گوشه کارت‌ها: ۱۸ تا ۲۴px
    - نورپردازی: لوکس، نرم، کم‌کنتراست، با هایلایت طلایی
    - ممنوع: عکس شلوغ، چهره‌های غیرواقعی، دست‌های خراب، متن‌های انگلیسی، نوشته‌های ریز زیاد، رنگ‌های نئونی، پس‌زمینه آبی سازمانی، کارت‌های خیلی گرد فانتزی

    ## قالب عمومی پرامپت

    برای هر تصویر این بخش ثابت را اول پرامپت بگذار:

    ```text

Dark warm luxury background #0e0d0b, charcoal UI cards #171512, gold accents #c9a24a and #e0c06e, warm white text #f4f2ee, muted text #9c988d. Persian text must be accurate, readable, right-to-left, using a modern Persian font similar to Vazirmatn. Leave safe margins. Do not add random English text, fake logos, extra unreadable text, distorted hands, distorted faces, or unrelated objects.
    ```
